验收日期：2026-11-05。每个案例各用两个独立 StudyUI 会话交互；配置模型为 DeepSeek `deepseek-flash`、思考等级 `high`。用户提供研究目标、公开仓储和本机文件路径，不提供节点名称、端口、节点参数或建流步骤。工作流由 StudyUI 主 Agent 调用 Harness 工具创建与调整；验收只读检查流程和产物，没有直接编辑工作流文件。

## 调教记录

- 电池 Skill 更新为 1.1.0，加入充放电分别筛选、保留有效样本、分组统计与分布检查节点的准确用途，以及禁止伪造分组的规则。第二次复核后报告删除了错误的“节点目录查询额度耗尽”解释。
- DNA 等离激元 Skill 更新为 1.3.0，并将仪器数组读取的必要数据契约写入 Agent System Prompt：读取 HDF5/NetCDF/Zarr 必须存在真实信号路径与匹配的一维坐标轴；二维数组还需明确光谱轴和唯一曲线标识。节点不会推断轴、转置或自动展平。
- 原始数据完整性 Skill 已明确本机确定性读取与 AI 子代理数据传输的区别；报告、工具输出和图表不把文件哈希、结构摘要或派生摘要混称为原始数据。
- 会话附件列表按文件名取最新版本，并对相同 SHA-256 的重复内容只显示一份；历史附件仍可按原 ID 下载。

## 结论与待补项

四个案例（混凝土、XRD、电池、DSC）在两个独立会话中均成功构建并运行了本地确定性流程；其中的数值结果按表中范围独立核对。DNA 案例目前只能稳定完成原始 HDF5 结构审查，缺少读取节点必需的坐标与标识数组，不能据此声称已重现论文的等离激元力结果。五类工作流均未使用 AI 分析子代理；这些案例验证了主 Agent 的 Skills 预检、节点组合、运行与报告，不构成 SubAgent 图像/表格分析功能的验证。

这组重复数据主要用于针对已发现问题的回归，不能证明对未见材料体系、任意数据结构或单轮交互都稳定。工作流节点连线、权限边界及运行入口另有 UI/API 验收；本文件的流程数量检查不替代浏览器视觉核查。原始数据、工作流、SQLite 会话和运行附件保留在本机运行目录，不提交到仓库。
