验收日期：2026-11-05。模型档案设置为 `deepseek-flash`、思考等级 `high`。五项任务分别从新的 StudyUI 项目会话开始，提示只描述研究目标、公开来源、原始文件位置和输出要求；由 StudyUI Agent 检查数据、选择科研节点、建流、运行并生成报告。PbS 光谱另在空白项目中重做一次隔离验收，以排除旧会话中混入其他实验工作流的影响。

## Harness 与 Agent 观察

- 五项实验都由自然语言驱动，最终工作流在画布 JSON 中具有有效节点端口与连线；验收图均不依赖 AI 分析节点，原始测量行留在本机。
- 多组任务需要用户自然语言纠错或一次性审批交互，不是“五项都在首轮零追问完成”。典型问题包括模型连接中断、单位字段不匹配、错误的多列交集过滤和旧会话上下文误选工作流。
- 隔离 PbS 会话暴露了权限意图识别漏掉“完成并运行工作流”、一次请求内重复生成附件、报告体积过大和死节点残留；Agent 随后自行清理死节点并核正来源说明。通过五组测试后，Harness 增加自然语言建流意图覆盖、总工具调用预算、每轮最多四次工作流运行，以及禁止无变化重跑、重复导出和默认导出完整节点运行记录的 Agent 指令。
- DataCite 针对 DOI 的真实查询成功返回 Zenodo PL 记录。Agent 报告曾把查询失败误说成“没有元数据”；已通过自然语言要求它重新核对并生成修订报告。Harness 系统提示现要求区分仓储声明与文件内事实，并在检索错误时如实报告错误。
- 新增/调整后的 Harness 控制由目标测试集验证：**79 项通过，7 项第三方弃用警告**。这些新增限制尚未通过另一整轮五数据集盲测，因此本记录不把它们称为已经彻底调教到稳定最优。
