# 文献方法辅助分析：验证记录

验证日期：2026-11-06。功能及操作说明见 [使用指南](evidence-guided-analysis.md)。

## 验证范围

- 科学计算：已知多项式的 SG 导数、AsLS 基线、SNV 零方差保护、峰特征尺度及单位。
- 化学计量学：独立调用 sklearn 对照；训练折内拟合；样品/重复组隔离；扰动测试集不改变训练模型。
- 方法建议：来源完整性、未知条件、不匹配信号、强度保留要求、不可执行方法及组合限制。
- 执行：依赖失效、显式局部修订、预算、循环/副作用拒绝、记录篡改检查。
- 结果追溯：引用实际表单元格、校验表指纹、关联上游参数与来源、区分观察/解释/推测。
- 集成：仓库保存及重新生成的四条工作流分别执行；原生 Langflow 浏览器操作；独立目录安装 wheel。

## 真实界面验收

四条示例在独立 Langflow 服务中通过。操作包括导入、连接执行、下拉修改、保存后读取及查看结果；没有输入高级 JSON，未记录浏览器脚本错误或失败的 API 请求。

| 示例 | 核对结果 |
|---|---|
| 光谱与证据 | 合成峰位 720 nm；AsLS 候选 eligible；结果单元格、单位、表指纹与上游计算一致 |
| PLS 独立测试 | 30 个训练、10 个测试样品；选择 4 个成分；测试 RMSE 0.01248417；两侧样品 ID 不重叠 |
| 分步分组分析 | 两组各 4 行；标准化后均值约 −0.912871、0.912871；保留中间结果及执行记录 |
| 不兼容方法 | 保留绝对强度时 SNV 为 blocked；无可执行映射；原生下拉修改保存后读回一致 |

局部重算另由 `examples/analysis_plan_demo.py` 及任务图测试核对：三步初算、修订影响两步、相同输入重复运行零次计算。跨组件实例或服务器重启不保证复用。
