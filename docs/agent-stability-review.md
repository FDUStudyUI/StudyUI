# 材料科研任务与 Agent 稳定性升级：审核说明

日期：2026-11-23。开发分支：`fix/agent-stability-review`。团队审核后再合并 `main`。

## 产品变化

研究会话增加 **材料任务** 入口。上传文件、选择列与单位、填写方法参数，检查通过后直接生成可编辑节点。内置 9 条真实仪器案例，覆盖铝/黄铜/钢拉伸、三种矿物 XRD、三份 PET Raman。

表单建流和这些流程的画布运行直接调用本地计算；聊天保留自由规划、改流和诊断。结果包含完整表格、图片、HTML 报告与可下载的复现包。

操作指南：[材料任务](../materials-quality/docs/material-tasks.md)。数据与许可：[来源清单](../materials-quality/src/materials_quality/material_examples/SOURCES.md)。

## 评委意见的落实

**材料特色：** 三类任务包包含任务、方法前提、方法卡、参数表单、原生节点和真实案例。方法卡由项目编写，记录版本并链接 ASTM E8/E111、BIPM、SciPy 算法说明和 IUCr 等来源。

**典型流程：** 拉伸表依据面积和标距换算工程应力/应变；加载段筛选、排序和拟合区间显示在流程中。光谱与 XRD 输出可接统计节点的峰特征。绘图使用分析后的有效坐标，避免未排序原表触发绘图失败。

**真实仪器评测：** 9 个文件来自三项公开数据集，原始字节保留。冻结流程在三个全新 Python 进程重跑。独立参考实现直接读取文件，用最小二乘求和公式、偏移线交点或局部极大值/突出度定义核对结果。

**方法与重复性分开：** `method_contract` 核对实际节点的方法、单位、区间与阈值；12 个条件异常案例验证补信息与换方法判定。`repeatable` 比较新进程结果表的哈希。材料专家对选段、背景模型和物相解释的独立评分另设字段；未收集时记录 `not_collected`，不会用运行成功代替专家评分。

真实模型测试增加 `--live`，用环境变量提供地址、模型名和密钥。本次使用用户的临时 DeepSeek 凭据；凭据未写入代码、文档、项目设置或提交。

最终验收摘要与失败基线见 [验收记录](../materials-quality/docs/stability-evaluation.json)。详细本地记录保留在开发目录 `materials-quality/artifacts/`；CI 归档测试产物。真实仪器 live 模式先按固定公开步骤准备测量表，建流分数不包含原始仪器格式转换。

| 实测项目 | 结果 |
|---|---|
| 全量自动测试 | 本地 1773 通过、10 跳过；画布补丁另经 14 项相关浏览器测试和 8 条完整案例复测 |
| 原始仪器参考流程 | 9/9 执行及独立数值对照通过；每条在三个全新进程中结果一致 |

| 浏览器材料入口 | 力学、Raman、XRD 三例通过，未调用模型 |
| 原有五个展示案例 | 5/5 通过，连续第二次运行的完成提示正常 |
| 安装包 | 70 个组件、原有案例、9 条真实仪器原文件哈希与协议编译通过 |

通用节点目录开放后的上一组真实测试，9 条均能建流，但仅 5 条完成执行与评测。原因包括绘图列/单位接错及所需特征端口未执行。新增材料任务工具入口后，同一组 9 条全部通过。两个批次完整保留；该结果针对固定的三类任务和九份数据，不作为任意材料任务的总体成功率。

## 审核操作

1. 打开真实案例，在画布运行并下载图、报告和复现包。
2. 再次运行，检查分析步骤的 `checkpoints` 是否为 `reused`；改拟合区间或突出度后应重新计算。
3. 解压复现包，运行 `python -m materials_quality.agent.run_bundle <目录>`；改动原始文件后哈希核验应指出不匹配。
4. 缺少必要单位、坐标重复或方法不适用时，检查具体处理建议。
5. 聊天等待模型时取消，再提交新任务；刷新后可找回原任务与保存的流程。

## 适用范围与部署

快捷入口覆盖三类单曲线描述分析。原有批处理、统计和其他材料节点继续保留。XRD 候选峰需要结合参考谱判定物相；拉伸模量取决于选段及测量条件；实验重复的独立性需依据实验设计确认。

模型仍可能限流、超时或选择错误方案，成功率按实际测试报告。第三方原生计算在下一检查点响应取消。检查点仅覆盖明确声明的纯计算；导入、绘图、导出和外部请求实际执行。

新增 `pyarrow` 科学依赖，安装清单和 CI 已同步。开发与验收使用独立工作目录，原 main、工作流、会话和运行环境保持原状。审核合并后再安排部署切换。
