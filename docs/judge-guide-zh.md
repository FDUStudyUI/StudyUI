# StudyUI 通俗使用与评审指南（面向评委与新用户）

> **一句话概括**：StudyUI 是一个**装在自己电脑里的材料科学研究工作台**。你把实验仪器导出的原始数据交给它，AI 负责帮你搭分析流程、查资料、挑方法，但**真正算数据的永远是透明、固定、可重复的科学计算模块**；而且一旦数据不符合某个物理方法的前提（比如拿循环加载曲线算单调拉伸模量、拿单周电池数据推算 500 周寿命），系统会在运行中途直接拦住并说明原因，而不是硬着头皮给一个“看起来像模像样、其实算错了”的数字。

---

## 一、我们为什么要做 StudyUI？（项目意义）

材料科学研究者日常处理拉伸、光谱（Raman/FTIR）、XRD、电池循环、热分析（TG/DSC）等数据时，常常遇到两难：

1. **用传统软件（Origin / Excel / 各类仪器自带软件）**：每换一批样品都要手动点几十步，换个人复现往往因为选段、基线或单位微调而对不上结果。
2. **直接把数据丢给通用聊天大模型写 Python 脚本**：
   - **不可重复**：今天写一套脚本、明天换一种写法，结果飘忽不定；
   - **不懂物理边界会“瞎算”**：把透射率 `%T` 的向下吸收谷当正峰去寻峰、没有标准参考谱却直接宣布 XRD 物相鉴定结论；
   - **数据安全与隐私风险**：未发表的实验原始数据直接上传云端；
   - **黑盒难查错**：出了问题只看到一段报错或一个最终数字，没法像搭积木一样修改其中某一步的参数。

**StudyUI 的核心思路是把“AI 动脑”和“程序算账”彻底分开**：

| 常见痛点 | StudyUI 的做法 | 给研究者与评委带来的价值 |
|---|---|---|
| 大模型自由写代码、结果不可复现 | AI **不能**随意执行陌生代码，只能调用仓库里预先登记好的 **70 个标准科研节点**拼成可视化工作流 | 每一步的参数、输入来源、数据哈希都落盘保存；脱离大模型后也能在本地一键复现 |
| 忽略物理前提“硬算”出假结论 | 资产图谱写死适用范围，运行期 **`GUARD` 门禁**自动拦截越界数据，关键判断点弹出 **`HUMAN` 人工确认** | 明确知道系统“什么时候不该算”，把科研判断权留给研究者 |
| 报告只报数字、不提限制条件 | 导出的报告和离线 ZIP 复现包自动附带**“适用范围、未验证前提与技术限制”**专章 | 方便导师审核、同行评审和论文补充材料（SI）直接引用 |
| 实验室数据涉密不敢上云 | **本地优先**：只监听本机回环地址，API 密钥存系统凭据库，无模型密钥也能直接运行内置工作流 | 数据留在自己电脑里，敏感操作和外发数据都要人工点头 |

## 二、材料学科特色与核心升级亮点

结合现有 70 个科研组件与最新升级，StudyUI 围绕材料研究全链路构建了 5 项核心能力：

1. **覆盖 5 大典型材料表征任务（143 项结构化科学资产、70 个已登记科研组件、30 张典型任务方法卡与 11 张文献方法卡）**
   - **力学性能**：单轴拉伸应力—应变曲线、杨氏模量拟合区间检查、0.2% 偏移屈服强度。
   - **振动/电子光谱**：Raman/FTIR 基线校正、寻峰、多通道逐曲线批处理（自动区分透射率与吸光度）。
   - **X 射线衍射（XRD）**：带仪器头文本导入、峰位与 $d$ 间距提取；支持可选 **`pymatgen` 插件**，读取 CIF 晶体结构计算理论衍射谱并与实测峰做候选比对（显式标注“仅作候选比对，不替代 Rietveld 精修”）。
   - **锂电池电化学**：充/放电分支识别、SOC—电压曲线、单周容量核对与多周衰减分析；支持可选 **`PyBaMM` 插件**运行单电芯 `SPM`/`SPMe`/`DFN` 放电仿真，并按倍率与温度自动提示物理适用边界。
   - **热分析（TG/DSC）**：单段升温失重台阶、DTG 峰与特征相变峰提取（自动拦截升降温混排曲线并提醒核对升温速率与气氛）。
2. **可视化画布 + 原生中文表单**：工作流画布展示真实数据连线，点开任意节点都能用普通表单改列名、单位、拟合区间和阈值，不需要手写 JSON 或代码。
3. **跨重启断点续跑与离线复现包**：运行过程实时写入追加式事件账本（`events.jsonl`）与版本快照；哪怕中途软件关闭或重启，已完成的纯科学计算步骤可直接从磁盘检查点复用，不用从头算起。
4. **受控的知识库演进（人工审批，绝不自动改代码）**：系统可以从运行期 `GUARD` 拦截记录和专家纠偏中提炼“避坑经验”，生成声明式方法卡补丁；补丁必须通过“零回归校验 + 物理边界不可弱化检查 + 研究者手工审批”才会生效，支持一键回滚，且在评测模式下强制锁定关闭（`evolution=off`）。
5. **面向评委的三维度独立评测体系**：使用真实公开仪器数据，把以下三个问题彻底拆开统计、绝不混为一谈：
   - **维度 A（建流成功率）**：系统/智能体能不能根据真实仪器文件搭出合法、可运行的工作流？
   - **维度 B（计算可重复性）**：把工作流冻结并断开大模型后，在全新冷启动进程里重复跑多次，结果表 SHA-256 哈希是否 100% 一致、与独立闭式数学公式误差是否在容限内？
   - **维度 C（所选方法正确性）**：所选节点、单位和前提是否符合方法契约？面对 6 类典型“不该硬算”的反例（循环加载、透射率谷、无参考谱强行 XRD 定相、单循环外推寿命等），运行期 `GUARD` 能否全部拦住？同时自动导出**专家盲评打分表（CSV/Markdown）**支持材料专家独立打分回填。

## 三、系统能做什么、不能做什么（明确适用范围与限制）

> 详细机器导出清单见 [`docs/scope-and-limitations.md`](scope-and-limitations.md)。

| 场景类型 | 系统支持（适用范围） | 系统不支持 / 必须人工复核（技术限制） |
|---|---|---|
| **单轴拉伸力学** | 单调拉伸应力—应变曲线的弹性段模量与 0.2% 偏移屈服计算 | 不适用于循环加卸载滞回曲线、强非线性弹性体直接线弹性拟合；不会替你确认试样截面积与标距 |
| **Raman / FTIR 光谱** | 吸光度/拉曼强度谱的基线扣除、寻峰与多曲线批处理 | 禁止直接对透射率 `%T` 向下谷值做正向寻峰；多条扫描曲线不等同于独立生物/材料样品数 |
| **XRD 衍射** | 仪器文本导入、$2\theta$/$d$ 间距提取、可选 `pymatgen` CIF 理论峰位候选比对 | 无标准参考谱时**禁止**输出确定性物相鉴定；理论比对**不替代 Rietveld 精修**，未考虑择优取向与多相定量权重 |
| **锂电池电化学** | 单循环充放电容量核对、多循环衰减统计、可选 `PyBaMM` 单电芯基线放电仿真 | 单循环数据**禁止**外推长循环寿命保持率；单电芯模型不反映模组热耦合与长期析锂老化 |
| **TG/DSC 热分析** | 单段升温曲线的失重台阶与 DTG 特征峰提取 | 升温与降温混排曲线会被拦截；不同升温速率与气氛（$\text{N}_2$/空气）下的结果不可直接横向对比 |
| **外部计算集群** | 本机确定性数据分析与轻量可选求解器（`pymatgen` / `PyBaMM`） | 当前版本不调度 HPC/Slurm 集群，不直接运行 VASP / Quantum ESPRESSO 第一性原理计算 |

## 四、5 分钟上手使用指南

### 方式 1：Windows 评委推荐 —— 免安装便携版（最快，无需配环境）

便携包已内置 Python 3.10、全部基础依赖、70 个科研组件与 5 个演示案例，解压即用：

1. 下载并解压 `StudyUI-beta-demo-windows-x64-portable.zip` 到任意可写目录。
2. 进入解压后的目录，双击 `start_demo.bat`（或在终端执行 `.\start_demo.bat`）。
3. 浏览器打开 **<http://127.0.0.1:7880>** 进入主工作台；打开 **<http://127.0.0.1:7880/canvas/>** 查看可视化工作流画布。
   - 若 7880 端口被占用，可在命令行加上 `--port 7886`。

### 方式 2：macOS / Linux 从源码运行

需要 Python 3.10+（首次安装依赖需要联网）：

```sh
git clone https://github.com/FDUStudyUI/StudyUI.git
cd StudyUI
sh ./start_demo.sh --setup
```

以后再次启动直接运行 `sh ./start_demo.sh` 即可；如果只想检查环境而不启动服务，运行 `sh ./start_demo.sh --check`。

### 怎么体验？（就算没有大模型 API Key 也能直接看完整效果）

1. **零门槛体验（无需模型密钥）**：
   - 打开首页，直接看到 5 个材料演示案例：**钛合金拉伸**、**多通道光谱**、**组间比较**、**3YSZ XRD**、**锂电池循环**。
   - 点击任意案例上的**“打开参考工作流”**，就能在画布里看到完整节点连线，点开节点表单调整拟合区间或寻峰阈值，点击运行即可生成图表、数据表和带“适用范围与技术限制”专章的分析报告。
2. **接入大模型体验 AI 自动规划（可选）**：
   - 点击右上角**“设置 → 模型管理”**，填写任意兼容 OpenAI 接口的模型配置（例如 DeepSeek：`https://api.deepseek.com`），密钥会安全保存在本机系统凭据库，不会写入工作流文件。
   - 回到首页点击**“载入数据，交给 Agent”**，或直接上传你自己的 CSV/TXT/Excel 仪器数据，用自然语言告诉它你想做什么分析，按审批提示确认即可。
3. **可选材料求解器插件（按需安装）**：
   - 如果想启用 `pymatgen`（CIF 理论 XRD 比对）与 `PyBaMM`（单电芯放电仿真），在激活的 Python 环境中执行：
     ```sh
     pip install -e "packages/materials-quality[compute]"
     ```
   - 不安装也不会报错，系统会自动优雅降级并给出清晰的限制说明与安装提示。

## 五、给技术评委的 3 条一键验证命令

在仓库根目录激活虚拟环境后，你可以直接用命令行检验系统健康状态、运行三维度独立评测，以及核对全部自动化测试：

```sh
# 1. 一键环境与资产图谱自检（带 E01-E06 分层诊断码）
python -m materials_quality.cli doctor

# 2. 查看 143 项材料科学资产图谱摘要与零错误校验
python -m materials_quality.cli assets summary

# 3. 运行真实仪器数据三维度独立评测（输出 JSON/Markdown 报告 + 专家盲评表）
python packages/materials-quality/scripts/evaluate_materials_suite.py --output artifacts/judge-eval
```
