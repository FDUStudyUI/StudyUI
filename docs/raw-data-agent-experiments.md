## 发现和修正

- 画布与主界面共用本地端口；画布从 `/canvas/` 加载，工作流仍为 JSON。
- 组件目录查询按相关度排序，限制重复查询，并保留多选字段的列表属性。过长工具结果保持合法 JSON，避免组件端口信息被截成无效文本。
- 工作流摘要不再发送组件源码或嵌入的数据；缺失检查按列返回缺失数和比例，同时省略逐行记录。来源摘要保留明确的来源字段。
- 电池绘图最初因不完整值被节点拒绝；现在为充电和放电分别建立按所选两列删除不完整行的派生绘图支路，缺失检查仍作用于原始表。
- DSC 热分析节点需要仪器符号约定和速率。缺少证据时改为描述性绘图，并在工作流名称和说明中标明局限。

五条工作流通过画布接口重新读取，并校验节点、端口和连线句柄；该检查不等同于对实验结论的科学复现。部分工作流需多次自然语言纠错；模型服务曾出现连接中断，尚不能声称所有任务均可一次建流成功。
