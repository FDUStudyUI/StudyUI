# 科研技能运行层设计

用户已于 2026-11-03 要求直接推进完整实现。方案依据：项目根目录之外的《StudyUI科研Skill可行性与实施方案.md》。

## 目标与选择

采用项目内置技能、受控任务执行器和 Langflow 原生表单。开发助手专用技能不能满足交付，任意生成代码的执行器难以验证；因此以现有科学运算为统一数值实现，提供光谱、力学、组间研究三条任务。

用户可直接运行表单，或通过可选的兼容 chat-completions 服务建议任务。模型仅得到列结构和有限摘要，不接收原始记录；建议必须通过同一校验器。缺失单位、定义、试验设计和拟合区间时输出待补事项，禁止执行。

## 接口

- `skills.registry`：加载随 wheel 打包的三个 SKILL.md 与参考资料；声明固定、允许的任务，提供内容哈希与来源记录。外部技能仅检查和预览，不授予执行权限。
- `skills.planning`：`make_plan(table, task='auto', request='', parameters=None, proposal=None)` 返回版本化分析计划，包括字段建议、阻断项、警告、参数、数据与技能指纹。`validate_plan(table, plan)` 在运行前重做校验并拒绝过期数据、修改后的计划及未知参数。
- `skills.model`：显式开启的模型方案建议；服务地址与模型、密钥由环境变量配置。严格 JSON、长度/超时限制、无重试安装、无任意工具执行；错误返回清晰提示，不伪装为成功模型分析。
- `skills.execution`：`execute_plan(table, plan, output_dir=None)` 执行三种固定任务，返回数值表、特征表、曲线、分组结果、图件、解释和追溯。绘图复用项目科研规范。
- 两个原生组件：任务规划、任务执行。前者采用任务切换、动态列选择和数值字段；后者只接表格与计划，显式执行。无需用户编写 JSON。
- CLI：列出技能、预览外部技能、生成计划、执行受控任务；提供可复制命令及可导入教学流程。

## 科学与执行约束

- Python 3.10；不升级共享环境、不改旧节点语义。
- 光谱的单位、候选峰窗口显式声明；候选峰不是确认物理模式。每曲线保留失败和未检出状态。多曲线误差带说明统计含义。
- 力学应力/应变单位与弹性区间必填，逐样品保留完整曲线、指标和失败状态。
- 组间推断必须给出组、变量、测量值、技术样本、独立试验单位和设计；复用技术重复聚合与 Holm/FDR。
- 技能不运行任意脚本；路径和输出只由本地运行接口提供。报告 HTML 转义，原始表保持不变。
- 执行记录输入哈希、规范化计划、技能包哈希、方法、参数、软件版本、警告和文件哈希。
- 三技能随普通 wheel 安装可用；模型服务可选，无密钥时表单与 CLI 可执行。
