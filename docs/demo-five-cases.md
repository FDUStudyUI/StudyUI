# 五个演示案例：数据、参考流程和结果边界

从首页案例入口选择案例，可选择“载入数据，交给 Agent”进行自然语言探索，或“打开参考工作流”载入确定性参考图。参考入口无需模型密钥，也不会自动执行。打开画布后点击运行；修改节点中的列名、单位、拟合区间或阈值后重新运行。最后的报告节点输出 HTML，绘图节点输出 PNG，HTML 内嵌图件，可单独保存查看。

参考流程的原始输入节点固定为已核验样例，不应编辑其中的内嵌编码。分析参数仍可通过节点表单修改。分析新数据时，请使用“载入数据，交给 Agent”入口或上传自己的数据建立工作流。画布按“左侧输入主干 → 分析 → 并行图表/结果表 → 右侧报告”排列；电池案例分别显示充电、放电和原表保存支路。

这些文件由用户提供，原件位于 `demo_datasets/`；包内 `materials_quality/demos/data/` 是逐字节副本。缺少可核验的原始实验记录，因此统一作为演示数据处理。文件名、仪器样式文本和材料名称不证明真实材料身份或实验来源。每次读取校验 SHA-256；参考流程内的原始附件再次校验 SHA-256，然后经实际导入节点读取。

| 案例 | 实际输入 | 参考节点链 | 预期结果与范围 |
| --- | --- | --- | --- |
| 拉伸 | 401 点，1 个 `synthetic-1` 试样 | 原始附件 → 表格导入 → 力学分析；原表 → 曲线；汇入报告 | 按演示单位 MPa/fraction 和 0–0.0008 区间，E=200000 MPa，0.2% 偏移屈服约 202.010 MPa，最大记录应力 219 MPa。不能据此声称真实 Ti64 性能。 |
| 光谱 | 4008 点，8 条曲线，A/B 各 4 条 | 原始附件 → 导入 → 逐曲线光谱分析 → 分组描述图、峰特征 CSV → 报告 | 常数基线 2 counts、突出度 0.5；每条 2 峰，共 16 峰。650–850 nm 窗口候选从 700 到 770 nm。组均值 715/755 nm，仅描述，未确认曲线独立性。 |
| 组间比较 | 24 条技术测量，8 个独立单位，每单位 3 次重复 | 原始附件 → 导入 → 实验单位聚合与 Welch 检验 → 单位均值图、CSV → 报告 | 每组独立 n=4，均值 1.6/5.6，Welch p≈0.004659，Holm 校正。单位 a.u. 为演示设定，独立性按文件列解释。 |
| XRD | 18 行注释、1 行列头、3001 数值点 | 原始附件 → 显式读取 A19:B3020 → XRD 候选峰 → 图 → 报告 | 线性基线、突出度 100 cps：30.2、35.1、50.4、59.8、62.8°。无参考谱库，不鉴定物相，不进行结构精修。 |
| 电池 | 单循环 1000 点，充/放电各 500 点 | 原始附件 → 导入并保存原表 → 按 Step 分两支 → SOC 透视 → 两张曲线 → 报告 | 使用文件 SOC 列绘图，不能推断寿命、保持率或库仑效率。容量列末值 2794.4 mAh，与每段 4990 s × 1.5 A 的积分约 2079.17 mAh 不一致，报告明确保留此问题。 |

图上的参数是演示选择，不是自动验证的科学最佳参数。拉伸末点不等于已确认断裂点；XRD 峰宽未扣除仪器展宽；统计显著性不证明实际材料有效；电池 SOC 未校准。全部来源说明、单位解释和限制进入最终报告。

没有项目的首次使用会新建演示项目与会话，原有未分类对话保留。选择案例后，点击画布右下角“运行工作流”，运行完成会回到会话显示图表、表格和 HTML 报告下载入口。

## 包内接口与维护

`materials_quality.demos.catalog` 提供 `list_datasets()`、`get_dataset(id)`、`read_demo_bytes(id)`；`materials_quality.demos.reference.load_reference_flow(id)` 只允许清单中的固定 ID，返回新的原生 Langflow 图。源数据及存储流程均校验 SHA-256。图内 `studyui_reference.nodes` 给出 source、import、analysis、plot、report 等稳定角色；电池另有 charge/discharge 及各自的图节点角色。

修改参考图构建器后，在 `packages/materials-quality` 下运行 `python -m scripts.build_demo_examples`，会重建 `demos/flows/` 及流程校验清单，不改动原始数据或元数据。请随后运行 `tests/test_demo_reference_flows.py`：它执行存储图，而非直接调用构建器，核对原始字节、实际导入结果、数值、生成图件和 HTML 内容。独立验收脚本进一步从原文件计算数值预期。
