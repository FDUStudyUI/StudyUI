# 科研可靠性演示流程

适用版本：0.7.0。在 Langflow 导入对应流程 JSON，再选择同名 CSV。JSON 为保存的画布文件，普通使用通过节点表单完成，无需编辑其内容。[原有技能示例](../skill_flows/README.md)继续保留。

| 流程 | 输入 | 观察目标 |
|---|---|---|
| [competing.json](competing.json) | [competing.csv](competing.csv) | 730/790 nm 竞争峰：两种候选规则给出不同候选，同时保留歧义 |
| [nested.json](nested.json) | [nested.csv](nested.csv) | A/B 各 3 个样品、每样品 2 条曲线：按样品均值比较，A−B 为 −30 nm |
| [small_n.json](small_n.json) | [small_n.csv](small_n.csv) | 每组仅 2 个独立单位：默认保留描述，p 值和推断区间缺失 |
| [all_failed.json](all_failed.json) | [all_failed.csv](all_failed.csv) | 数值输入全部失败：结果仍保留失败记录与错误原因 |

## 运行顺序

1. 将 CSV 数据源的表格同时连接到“科研技能·任务规划”和“科研技能·分析执行”；将规划输出连接到执行节点的分析计划输入。
2. 在规划节点选择光谱任务，检查曲线、波长、强度、组别映射，以及 nm 和强度单位；确认候选窗口。
3. 选择候选规则、阈值来源和统计单位方式，核查相应确认框。先运行规划节点，再运行执行节点。
4. 查看逐曲线结果、结构化峰特征、分组表及 HTML 报告。保存后重新打开流程，复核原生控件值；修改参数后重新生成计划。

## 四个可复核结果

**竞争峰。** 使用“指定突出度阈值”保持同一检测阈值，分别选择“突出度最大候选”和“最红端候选”。两次分别得到约 730 nm 与 790 nm；`candidate_count=2`、`ambiguous=true` 均保留。`window_candidate_nm` 为正式候选字段，`lambda10_nm` 为等值兼容别名。

**样品内重复。** 选择“按样品汇总后比较”，映射独立试验单位列，并勾选“确认所选单位在组间独立，技术重复按单位汇总”。A/B 各 6 条曲线先汇总为各 3 个样品均值，比较中的 `n_a=n_b=3`，差值为 A−B，约 −30 nm。曲线级检出分母、样品级推断样本量分别显示。

**小样本。** 保持“小样本处理”为“默认仅描述”。每组 n=2 时，报告描述差值，`ci_status=not_estimated_small_n_policy`，p 值和差值置信区间保持缺失。高级选项“显式模型推断（需检查假设）”可单独演示 n=2 的模型推断状态；开启前核查正态/配对及独立单位依据。

**全部失败。** 查看任务 `failed` 状态、逐曲线错误和失败分母。输入与契约校验失败时先修正原始输入，再重新规划；已生成的报告和失败行用于追溯。

## 图件与核验范围

IQR/SD 为描述带。`ci95` 要求确认独立单位，以单位均值曲线计算逐点区间；默认每组至少 3 个单位，显式模型政策至少 2 个，测量网格需一致。网格不一致会保留数值结果并解释未生成置信带的原因。

这些流程用于检查候选规则、统计粒度和失败路径。科学含义见[科研可靠性说明](../../docs/research-reliability.md)，合成数据与统计模拟的条件性结果见[独立评测](../../docs/evaluation-reliability.md)。导入、保存重开及目标运行环境的完成状态，以固定提交对应的验收记录为准。
