# 科研技能示例

三个流程均包含 **数据源 → 科研技能·任务规划 → 科研技能·分析执行**，共 3 个节点、3 条连接。
数据嵌入流程，导入后可直接运行；CSV 为同一份合成数据，供练习上传使用。

| 流程 | 输入 | 独立预期 |
|---|---|---|
| [光谱](spectra.json) / [CSV](spectra.csv) | 8 条曲线，每条 501 点 | 16 行峰特征；A/B 各 4 条窗口候选，均值 715/755 nm |
| [力学](mechanics.json) / [CSV](mechanics.csv) | 20 份拉伸试样 | 20 项完成；首份模量 200000 MPa，0.2% 偏移强度约 202.01005 MPa |
| [组间研究](contrast.json) / [CSV](contrast.csv) | 两组，每组 4 个试验单位，各有 3 个技术重复 | 原始 24 行聚合为 8 个单位；各组 n=4；一项 Welch 两两比较 |

## 操作

1. 在 Langflow 首页导入对应 JSON。
2. 运行“科研技能·任务规划”，查看“步骤与待补事项”。
3. 确认单位、窗口或弹性区间，运行最右侧“科研技能·分析执行”。
4. 查看“逐样品/试验单位结果”“结构化特征/两两比较”“分组描述统计”和“结果摘要”。
5. “图件与导出文件”列出服务器上的 HTML、CSV、图件和文件哈希清单。HTML 包含图像，可单独打开。

光谱练习：将规划节点的候选窗口下限从 650 改成 720 nm，先运行规划节点、查看新计划，再运行执行节点。
A 组有效候选变为 2 条、均值 725 nm；B 组保持 4 条、均值 755 nm。改回 650 后按相同步骤恢复原结果。

替换为自己的数据时，把数据源换成“表格文件导入”，将同一张表分别连接到规划和执行节点，保留规划到执行的计划连接。
使用长表：每一行是一个测量点，曲线/样品编号区分不同对象。上传前保留标识符前导零；导入节点可显式设置文本类型。
