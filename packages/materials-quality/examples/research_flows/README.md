# 光谱特征与区间绘图

这里使用 8 条合成光谱，每条都有 530 nm 峰及一个较长波长的候选峰。A、B 两组各 4 条独立曲线，
候选峰中心分别为 700/710/720/730 nm 和 740/750/760/770 nm。

- `01_eight_curve_features.json`：逐曲线分析 → 筛选指定窗口内的候选特征 → 分组统计 → HTML 报告。
  两组候选峰均值应为 **715、755 nm**，各组 `count=4`。
- `02_eight_curve_bands.json`：逐曲线分析 → 均值和真实 IQR 填充带 → HTML 报告。
  每组按完整曲线计算四分位带，不把四分位值画成额外普通曲线。

窗口 650–850 nm 是本合成案例的设置，不是论文通用判据。λ₁₀ 的物理模式归属需结合实验判断。
刷新组件目录后导入 JSON，运行最右侧报告节点。每个节点的表格输出可独立查看。
配置方法和字段含义见[批量分析指南](../../docs/batch-processing.md)。

重新生成：`python -m scripts.build_research_examples`。
