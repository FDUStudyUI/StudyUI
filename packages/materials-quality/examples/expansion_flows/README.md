# 同批样品、校准、电学与电池工作流

适用版本 0.8.0。将流程 JSON 导入 Langflow 即可运行。每份流程内嵌合成样例；同目录 CSV 用于换文件练习。节点参数在表单中填写，流程文件由 Langflow 保存和导入。

| 示例 | 怎么运行 | 可核对的结果 |
|---|---|---|
| [同批光谱与电学](specimen.json) | 检查光谱窗口、I–V 区间和样品主表，运行右侧分析报告。 | 6 个样品。候选波长 700、705、710、730、735、740 nm；对应电阻 200、250、500、100、125、200 Ω。 |
| [拉伸信号标定](mechanics.json) | 在归一化节点查看三个标准对，运行右侧分析报告。 | 原始桥路信号保留，新增 MPa 应力；弹性模量 200000 MPa。 |
| [光响应开关](photoresponse.json) | 查看暗态和亮态平台窗口、开关光时刻，运行分析。 | 幅值 8 μA；按 10%–90% 定义，上升和恢复时间均为 3.2 s。 |
| [逐电芯容量保持率](battery.json) | 确认容量单位 Ah，运行右侧分析报告。 | 每个电芯按自己的首个有效循环归一化，A 为 100%、90%、80%，B 为 100%、95%、90%。 |

## 用自己的数据

- **同批样品。** 主表的样品编号作为关联键，有重号时加批次列形成复合键。将主表连到多表合并的主表端口，各仪器的样品特征表连到多表端口。样品编号列保持文本类型。多次技术测量先在各方法内按正确条件汇总，然后关联。检查报告里的未匹配项、重复键和输出行数。
- **校准。** 在「数据归一化」选择扣空白、参考归一化或线性标定。输入单位、标准来源和新列名称。扣空白可填常数或同一行的空白列；参考归一化使用（信号−空白）÷（参考−空白）。线性标定填至少三个不同标准信号及对应已知值，默认拒绝超出标定范围。只在同一样品与条件的重复测量已经明确时选分组列，报告样本标准差和计数。
- **电学。** 先核对电压和电流单位，再明确拟合区间。往返扫描应以分支列拆开。光响应模板的暗态和亮态平台用窗口中位数估计，跨越阈值时作线性插值；未观测到完整跨越时保留状态和原因。
- **电池。** 循环汇总表需含电芯、循环编号和放电容量。原始记录模式需明确时间、电流、充放电阶段与电流方向。循环间保持率以声明的参考循环计算。库仑效率仅在同一循环充放电可比且用户确认时计算。

上游原始数据保留，报告记录输入、参数和失败状态。校准拟合残差、重复测量标准差和组间推断区间分别解释。
