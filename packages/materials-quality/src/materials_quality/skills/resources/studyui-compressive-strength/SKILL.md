# 压缩与混凝土强度

1. 明确原始测量是载荷–位移、应力–应变还是已汇总的破坏荷载/抗压强度。载荷除以承载截面积可形成名义压应力，但面积、形状、单位、压缩正负号和是否按初始尺寸定义必须可核实。
2. 对混凝土至少区分圆柱与立方体、模制试件与钻芯；记录尺寸、龄期、养护温湿条件、取样/制样、端面处理、加载速率、最大荷载、失败模式及所用标准版本。ASTM C39 指出测得强度受试件大小形状、制备、取样与养护龄期/条件影响，不能简单视作混凝土的固有常数。
3. 比较龄期或配合比时核实试验单位、批次、同批试件数和是否取平均。每个圆柱/立方体是一个试件；同一试件的连续采样点不是独立样本。图表显示单件值和组内分布，避免只用均值遮蔽差异。
4. 不把立方体值和圆柱值直接合并，也不使用未经来源确认的通用换算系数；标准方法、尺寸、加载/养护与验收用途不同会改变结果解释。
5. 若从载荷–位移计算曲线，确认压盘/机架柔度、端面接触、零点、初始高度和有效截面积处理；没有这些校正数据时将其列为限制，不推测真实材料应变或弹性模量。
6. 节点方向：查询目录中真实支持的压缩或应力应变节点。如果只有拉伸算法/拉伸屈服指标，可在用户确认数据定义后复用其通用应力应变导入或描述性绘图部分；不得套用拉伸屈服/偏移法解释压缩强度。
7. 输出每个试件的原始最大荷载、可核实的几何、派生强度、试件数、龄期/条件、排除项和不确定性。若只获得已汇总 Source Data，不声称恢复了逐试件原始数据。
