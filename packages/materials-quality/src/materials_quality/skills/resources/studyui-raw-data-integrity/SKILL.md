# 原始数据身份与质量审查

1. **先确认数据层级。** 标记为仪器原生文件、仪器导出数值、论文/仓储 Source Data、补充材料或他人已变换数据。若元数据没有说明，不推断其是否应用了背景扣除、归一化、校正、平滑、积分或汇总。
2. **记录来源身份。** 保留下载链接/DOI/记录号、文件名、仓储版本、获取日期和文件 SHA-256。分析支路不得覆盖源文件；导入、转换和筛选结果都应保留节点配置及新文件身份。
3. **核对结构再映射。** 用文件检查器确认工作表/分隔符、候选表头、数据区间、空值、数值列和行数。候选字段名只是线索；物理含义、单位、样品编号及组别必须由数据字典、论文方法或用户提供信息支持。
   - 对 ZIP 等归档，先检查成员清单，区分仪器原始记录、作者 Source Data、图表导出和处理脚本；不要因为文件扩展名、文件名含 `raw` 或仓储页面称 `source data` 就推断全部成员均未经处理。
   - 对 HDF5 等层级数据，优先检查组/数据集路径、形状、数据类型和采集标记；大数组先用目录或受限读取确认范围，避免把整个文件转换或复制为表格。报告实际检查的组、数据集和未覆盖范围。
   - Harness 的 `instrument_structure` 是本机从 HDF5 browse 表压缩的安全摘要，只含受限路径模式、shape、dtype、计数与覆盖，明确不含 attrs 值。可直接用它规划后续本地导入，不要为拿到路径而把 4103 行 browse 表发送给模型。
4. **验证原样覆盖。** 对重复表头、注释行、稀疏组标签、多表、多曲线、空行、重复记录和非单调采集做显式检查。计数输入行、可解析数值行和有效分析行；过滤/缺失处理应另报保留与排除数量。
5. **不修补未知。** 不把空值填零，不推断误差列、时间轴、样本数或单位；不把缺失标签当新等级。只有来源说明支持时，才在派生支路继承区块标签，并保留原始列及行数核验。
6. **保留采集次序。** 不对真实采集时间、滞回曲线、循环过程、力学加载路径按坐标排序或重采样，除非方法明确要求且原序列仍可恢复。
7. **最小化外传。** 确定性节点可在本机读取并处理原始数组；Harness 返回主 Agent 的 `run_workflow` 结果会压缩表格端口，不包含完整测量行。不得仅因本地节点接触原始数组就放弃可行分析。AI 分析节点会把指定上游数据发送给模型，须先说明具体范围并遵守 StudyUI 的单次授权策略；attrs 原文、完整 browse 表和原始测量行不得通过任何其他报告或工具参数发送给模型。
8. **形成数据字典。** 报告列名、单位、角色、样本/曲线标识、未知项、任何变换、来源哈希和处理后范围，足以让他人从同一原始文件复核。
9. **选择导入路径。** 若是层级仪器文件，查节点目录中的仪器/HDF5/数组读取节点并按目录的真实端口建流；不要自行写脚本解包、摊平或另存成 CSV 来绕开节点能力。现有节点无法保留样本层级时，报告这个覆盖缺口并停止不等价替代。

## 输出检查清单

- 来源与数据层级：可核实 / 部分核实 / 未核实。
- 文件哈希、工作表/数据区、解析行数与列数。
- 原始字段 → 节点输入端口映射，以及单位证据。
- 排除、缺失、转换、筛选和数据覆盖范围。
- 未确认的语义、采集条件和测量校准。
