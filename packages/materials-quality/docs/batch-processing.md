# 批量分析与可视化配置

普通任务使用下拉框、勾选项、数值框和规则表。高级 JSON 留作旧工作流和特殊参数的兼容入口。
升级组件包后，重新启动 Langflow，再导入新示例。正在运行的旧服务可能缓存旧端口定义，不能仅替换文件后直接验收新版多文件输入。

## 多份文件用一条流程

连接「文件与样品入口」的**批次数据**到后续节点的**输入数据 / 上游追溯**，沿流程继续连接「结果与追溯」。
批次连接传递每份样品的完整表格，不是报告中的前几行预览。无需复制每个样品的节点。

推荐流程：

`批量入口 → 表格导入 → 共享质量检查 → 力学分析 → 力学绘图 → 结果汇总`

1. 在入口选择 `files`，打开文件管理器，多选 CSV、Excel 或仪器文件。
2. 统一字段时，在「列名统一」中填写原名和标准名。服务器用户也可以在高级项填写 glob，例如 `data/*SERS map.csv`。
3. 选择「文件条件来源」为 `parent`，使用父目录名生成 `group`；`filename_prefix` 使用文件名前缀。已有 `group` 冲突时会报错。
4. 在后续分析节点选择方法、列名、单位、窗口和阈值。参数对批次中每份样品分别生效。
5. 运行末端「结果汇总」。查看每份样品的状态、质量发现、分析指标和失败原因；打开 HTML 查看完整来源及运行记录。

每份文件是一项任务。单份文件里包含很多颗粒或试样时，先读成表格，再使用入口的 `grouped` 模式，选择样品列。
一组包含该样品的所有测量点，不能把每个点当作一条独立曲线。

`continue` 会保留单项错误并继续其他样品；`stop` 会终止当前操作。质量问题与程序失败分别记录。
默认质量检查不会自动删除样品；启用「发现问题时跳过后续分析」才会跳过。原始文件和值始终保留。
文件在入口读取后发生变化时，需重新运行入口，以更新来源指纹。

## 光谱批处理

「逐曲线光谱分析」直接接收长表：

| curve_id | x | y | group |
|---|---:|---:|---|
| particle-001 | 500 | 12.3 | control |
| particle-001 | 501 | 12.7 | control |
| particle-002 | 500 | 10.1 | treated |

选择曲线 ID、坐标、强度和可选分组列，明确坐标和强度单位。每条曲线独立扣基线、平滑、寻峰和积分。
输出包含完整处理曲线、逐峰特征、每条曲线摘要、分组统计及警告。无峰与计算失败有独立状态，不会从样品清单消失。
组间统计按每条曲线的主峰汇总，不把同一曲线中的多个峰当作独立实验重复。

原有「光谱分析」「XRD 分析」也有**峰值特征表**输出，可继续连接统计节点。峰位、突出度、FWHM、面积与单位不必从文字报告复制。

### λ₁₀

[Rocchetti 等的论文](https://doi.org/10.1021/acs.nanolett.3c01016)中的 λ₁₀ 表示最低能量耦合等离激元模式的共振波长。
本节点提取的是**指定窗口内的候选峰**，不自动证明物理模式归属，也不声称复现论文未明确提供的拟合程序。

启用 λ₁₀ 后，按实验设置搜索窗口，选择「突出度最大」或「最红端」候选。多个候选会标记歧义；没有候选则输出缺失及警告。
长度单位换算为 nm；波数和能量不会在此处自动反演。710 nm 不是通用默认值。

论文的[公开数据仓库](https://www.repository.cam.ac.uk/items/5fb76156-d930-455c-98c5-3ee330e02fe7)
提供源数据及许可说明。仓库自带示例是合成数据，用于验证流程和已知数值，不冒充论文实验数据。

## 时间、组间比较和显微图

| 节点 | 填写内容 | 主要结果 |
|---|---|---|
| 时间动态分析 | 曲线 ID、时间、数值、时间单位、平滑与阈值 | 完整时序、尖峰、增长段、描述性变化点、趋势与 HAC 区间 |
| 实验组对照研究 | 组别、变量、数值、技术样本 ID、独立实验单位 ID | 单位均值、描述统计、总体与两两检验、效应量、Holm/FDR 校正 |
| 批量显微图 | 多张图、阈值/分割、统一标尺或逐图标尺表 | 每图状态、真实区域特征、粒径与分组汇总 |
| 多模型比较 | 特征、目标、模型列表及验证方式 | 同一拆分下的各模型分数和预测记录 |

技术重复先按独立实验单位取均值，再参与组间推断。配对设计要求 ID 完整匹配。
时间序列的 `chronological_split` 按时间留出，`blocked_cv` 只用过去训练、未来评估。普通随机拆分仍适用于合适的独立样本。
时序趋势区间与训练域内均值区间均不是未来预测区间。缺少物理标尺的图像只报告像素单位。

## 分组、公式与区间绘图

- 分组统计支持多个分组键，输出长表或宽表；可按组除以自身均值。
- 归一化支持按曲线、样品或条件分组，分别拟合 minmax、zscore 或 robust 参数。
- 筛选节点的「派生列」规则表支持受限算术表达式；填写列名、表达式和单位。不能执行 Python 代码。
- 光谱绘图的 `band` 方法按完整曲线绘制均值与四分位带、样本 SD 或逐点 95% t 区间。
  不同网格需显式指定公共范围内的插值网格，不外推。置信带至少需要两条独立曲线。

## 仪器数组

安装数组依赖：`pip install '.[instruments]'`。HDF5、NetCDF、Zarr 可先选择 `browse` 查看数据集路径、形状、类型与属性，
再选 `read`，填写信号、坐标和曲线标识路径。二维数据必须明确光谱轴，避免自动转置误读。
可选择背景、参考和噪声窗口；无效参考通道会标记，不会伪造正常数值。

当前读取对象为本地一维或二维数值数组，Zarr 使用本地目录。对象数组、外部链接等不会作为普通信号读取。
当前 Python 3.10 环境支持 Zarr 2；Zarr 3 的数据读取需兼容的 Python 和依赖。浏览器上传 Zarr 目录需先在服务器准备目录路径。

## 示例与旧流程

`examples/batch_flows/01_twenty_specimens.json` 内嵌 20 份合成拉伸试样，可直接导入运行。
`02_twenty_files_upload.json` 使用同目录 `twenty_csv/` 的 20 份 CSV，在界面多选上传后运行。
两条流程各 6 个节点，试样数增加不要求复制分析节点。

`examples/research_flows/` 提供 8 条合成光谱的候选峰→分组统计和均值→IQR 填充带示例。

升级旧流程可运行：

```powershell
python -m scripts.migrate_flow_ui old.json new.json --prefer-forms
```

可无损转换的已知参数进入表单；自定义代码、不认识的配置或有歧义的默认值保留高级 JSON，并在迁移报告中说明原因。
迁移前保留原文件。无需为普通新流程编写 JSON。

节点表单按可用输入刷新列名选项；上游未运行时可填写真实列名。结果表可查看前几行，报告记录行数、单位和来源。
自定义画布子流程折叠、全画布实时 schema 订阅和编辑器级校验标记不属于当前组件包实现；这些需要修改 Langflow 编辑器。
