# StudyUI 参赛对齐与证据清单

本文供团队整理初赛材料，依据已取得的大赛公告、项目源码和验收记录编写。外部《Gemini对项目的分析》作为评审意见参考，事实与建议分别核对。

## 参赛定位

推荐主赛道：**智慧学习与科研助手**。StudyUI 面向材料实验数据分析，将数据接入、质量检查、科学计算、绘图和追溯组织为可查看、可复跑的工作流；内置科研技能进一步提供任务规划与受控执行。

交付版本为 `langflow-materials-quality 0.6.0`：原有 60 个节点，加上“科研技能·任务规划”和“科研技能·分析执行”，合计 62 个原生节点；三个 SKILL.md 及其参考资料随安装包交付。主分支的历史 60 节点版本与本版本的验收应分别说明。

## 部署与模型边界

基础分析在运行 Langflow 的电脑或服务器执行。部署在远程服务器时，上传数据也会到达该服务器。选择文献服务、数据库、REST 接口或外部模型时，网络访问取决于节点与服务配置。

科研技能的模型建议默认关闭。启用后，请求包含任务描述、列名、类型、行数、缺失计数、单位及内置技能正文；程序不自动附加原始记录。用户写入描述的内容会随请求发送。模型服务需兼容 chat-completions，科学单位、窗口、弹性区间与试验设计仍由用户确认。
