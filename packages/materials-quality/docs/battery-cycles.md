# 电池循环与容量保持率

将数据表连接到 **材料批量·电池循环与容量保持率**。每条输出记录对应一个电芯和循环。选择电芯标识、循环序号及对应数据列，循环序号应为正整数。

| 输入模式 | 数据与设置 |
| --- | --- |
| `summary` | 每个电芯循环一行，包含放电容量和可选的充电容量。为所选容量列声明共同的单位 `Ah` 或 `mAh`。 |
| `raw` | 每行一个采样点，包含时间、电流和 `charge`、`discharge` 或 `rest` 相位。声明时间单位、当前电流单位及充放电符号。 |

原始模式按输入行顺序拆分每个循环中连续同相位的采样段。每段充放电至少两点，段内时间严格递增。梯形积分覆盖各段实测点之间的区间，跨相位间隔和静置段不计入容量。原始数据须按目标电压窗口完成裁切后再输入。若已量化仪器零点噪声，可设置反号电流容差，容差内的反号值仍计入净电流积分。

基准设为 `0` 时，每个电芯使用自身序号最小且放电容量有效的循环。指定正整数时，每个电芯都使用该序号，基准缺失时保留放电容量并标记为部分有效。容量保持率是放电容量与该基准的比值，以百分比表示。应确认各循环的电压窗口、倍率及温度可比后解释趋势。

确认同一循环的充放电容量来自可比协议后，可选择计算库仑效率。原始模式还要求同一循环内全部充电段先于放电段。结果表包含有效、部分有效、无效状态及原因，重复的容量汇总行与非法放电段对应的循环保留为无效记录。报告提供列单位、循环计数、基准规则、输入指纹和分析参数。循环记录是同一电芯的重复观测。

## NASA PCoE B0005 公开数据验证

使用 B. Saha 和 K. Goebel 的 Battery Data Set。NASA PCoE 提供下载，Data.gov 提供数据结构和测试说明。 [NASA PCoE 数据仓库](https://www.nasa.gov/intelligent-systems-division/discovery-and-systems-health/pcoe/pcoe-data-set-repository/) · [Data.gov 数据目录](https://catalog.data.gov/dataset/li-ion-battery-aging-datasets)

| 来源文件 | SHA-256 |
| --- | --- |
| [NASA 官方链接指向的 ZIP](https://phm-datasets.s3.amazonaws.com/NASA/5.+Battery+Data+Set.zip) | `82302a7db4fc1b34e0b6676326610438d43b816bdf11a69d1d012a464ef2f92e` |
| 嵌套压缩包 `1. BatteryAgingARC-FY08Q4.zip` 中的 `B0005.mat` | `0eae4585baf3f200c09fe24c5ab884f1889679fc75206ca1aa19da704104f0b0` |

从 MAT 文件的 616 条操作记录中按存储顺序提取全部 168 条放电记录，逐条将 `Time` 和 `Current_measured` 保留到首个端电压 `Voltage_measured ≤ 2.7 V` 的实测采样点。采样点按原时间及带符号电流传入分析，总计 45,458 点。2.7 V 截止来自数据包 README 对 B0005 的协议说明。积分端点采用首个满足截止条件的实测点。反号电流容差设为 0.01 A，覆盖所用区间内最大 0.005934 A 的反号观测。所有放电记录的环境温度字段为 24 °C。

参考值直接读取独立的 `data.Capacity` 字段，不进入积分输入。参考保持率另用每条记录的 `Capacity` 除以第一条记录的 `Capacity`。本次运行 168 条循环全部有效。

| 比较项 | 实测误差 | 验收上限 |
| --- | ---: | ---: |
| 放电容量最大绝对误差 | 0.0000223021 Ah | 0.0001 Ah |
| 放电容量平均绝对误差 | 0.00000138688 Ah | |
| 保持率最大绝对误差 | 0.00120131 个百分点 | 0.01 个百分点 |

参考放电容量由 1.856487 Ah 降至 1.325079 Ah。第 168 次参考保持率为 71.375616%，积分计算得到 71.375616%。这一对照验证同一电芯固定截止协议下的放电容量与保持率。库仑效率与多电芯基准使用解析测试验证。

安装 `.[science]` 后，在包目录执行以下命令。首次运行允许下载约 200 MiB。已有匹配 SHA-256 的本地 MAT 文件可省略 `--download`。

```bash
python -m scripts.validate_nasa_battery --download
```

源文件和衍生文件存放在 Git 忽略目录 `artifacts/nasa_battery/`。其中 `benchmark.json` 记录来源、方法、输入指纹和验收结果，`cycle_comparison.csv` 记录每个循环的参考值、计算值与误差，`b0005_cutoff_input.csv` 可接入原始模式复跑。界面参数选择 `s`、`A`、`discharge_negative`，反号电流容差设为 `0.01 A`。
