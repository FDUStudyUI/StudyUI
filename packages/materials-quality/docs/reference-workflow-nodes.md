# 材料科学节点与方法


## 1. 数据接入节点

- **表格文件导入**：识别分隔符与编码；选择工作表、表头行和数据区域。
- **文本文件导入**：识别编码；按行、分隔符或固定宽度解析。
- **PDF 文件导入**：提取原生文本；扫描件转换为图像后交给 OCR。
- **图片文件导入**：读取图片格式、尺寸、分辨率和元数据。
- **仪器文件导入**：按仪器文件格式解析；暂不支持的格式使用转换器或插件。
- **数据库接入**：SQL 查询；REST API 分页读取；按字段筛选。

## 2. 内容提取节点

- **PDF 文本提取**：按页提取；尽量保留段落和版面顺序。
- **PDF 表格提取**：根据表格线提取；根据文本对齐关系提取；OCR 表格识别。
- **图片文字识别**：OCR；版面区域识别；保留文字位置与识别内容。
- **图片表格提取**：检测表格区域、切分单元格并识别单元格内容。
- **图表数据提取**：校准坐标轴；识别曲线；将曲线数字化为数据点。
- **文件格式转换**：解析原始格式或转换为 CSV、TXT、PNG 等中间格式。

## 3. 数据质量检查节点

- **必需字段检查**：必需列清单；字段名别名匹配；数据结构模板校验。
- **缺失值检查**：统计数量和比例；按行、列、分组检查；分析缺失模式。
- **类型与格式检查**：推断字段类型；校验日期、数值和分类格式。
- **单位检查**：识别并换算单位；检查量纲兼容；标记混合单位。
- **重复记录检查**：完全重复检查；按样品编号检查；相似记录匹配。
- **异常值识别**：按物理范围规则检查；四分位距法；MAD 稳健离群值检测。

异常值节点应标记可疑数据并说明依据；是否删除或修正由研究者决定。

## 4. 数据预处理节点

- **行列筛选**：按条件过滤；选择、重命名字段；移除空行。
- **缺失值处理**：删除记录；均值、中位数或众数填补；前向或线性插值；保留缺失。
- **单位换算**：按明确的换算关系转换；保留原值和转换记录。
- **格式转换**：宽表与长表转换；日期、数值和分类字段转换。
- **多表合并**：按样品编号连接；按时间或容差匹配；纵向追加。
- **数据归一化**：Min-Max；Z-score；稳健缩放。

插值只适用于有序、连续数据等合适场景，不应默认用来补全缺失的实验结果。

## 5. 材料专业分析节点

- **XRD 数据处理**：背景扣除；平滑；峰检测；峰位与半高宽计算；物相匹配；全谱拟合。
- **FTIR/Raman 数据处理**：基线校正；平滑；峰检测；峰面积计算；谱线归一化；谱库匹配。
- **TG/DSC 热分析**：基线校正；失重阶段识别；峰温与起始温度计算；峰面积积分。
- **应力—应变分析**：弹性模量拟合；屈服强度计算；最大强度识别；断裂应变与曲线积分。
- **SEM/EDS 分析**：图像阈值分割；颗粒或孔隙识别；尺寸统计；读取元素定量结果。
- **显微结构图像分析**：阈值或机器学习分割；连通区域分析；粒径、孔隙率和面积分数统计。

专业分析通常需要对应的原始数据、校准信息和材料知识。例如，XRD 物相匹配依赖参考数据库；算法输出不能直接等同于确定的材料结论。

## 6. 统计与建模节点

- **分组统计**：样本数、均值、标准差、中位数、四分位数、最小值和最大值。
- **分布检查**：直方图、Q-Q 图；Shapiro-Wilk 正态性检验。
- **相关性分析**：Pearson；Spearman；Kendall。
- **显著性检验**：独立或配对 t 检验；Welch 检验；Mann-Whitney；ANOVA；Kruskal-Wallis。
- **多重比较**：Tukey；Dunn；Holm 校正；FDR 校正。
- **回归分析**：线性回归；多项式回归；岭回归；Lasso。
- **预测模型**：随机森林；梯度提升树；支持向量回归。
- **模型评估**：留出集验证；交叉验证；MAE、RMSE、R²。

检验方法应根据样本设计、重复测量关系和数据分布选择，不能只依据“算法能运行”来决定。

## 7. 可视化与报告节点

- **性能对比图**：散点图、柱状图、箱线图、小提琴图。
- **光谱或衍射图**：折线图、叠加谱图、差谱图、峰位标注。
- **应力—应变图**：曲线叠加；分组均值与误差带。
- **统计图表**：直方图、相关性热图、残差图、模型预测图。
- **结果表导出**：CSV、Excel；保留列名、单位和样品编号。
- **分析报告生成**：按模板汇总数据来源、节点参数、结果、图表和警告。

## 8. 文献与知识检索节点

- **文献搜索**：关键词、布尔检索、作者或 DOI 检索。
- **文献元数据提取**：DOI 解析；提取题名、作者、期刊和年份。
- **材料与性能信息提取**：规则和词典提取；表格解析；大模型结构化抽取并保留原文证据。
- **多篇文献对比**：按材料、制备方法、测试条件和性能指标对齐比较。
- **引文与来源记录**：保存 DOI、页码、表图编号和原文片段。
- **文献综述摘要**：检索相关片段；基于证据生成摘要；为要点链接来源。
