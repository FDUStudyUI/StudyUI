# 材料任务：从仪器文件到可复现结果

在研究会话顶部点击 **材料任务**。可以上传自己的文件，也可以展开 **从真实仪器案例开始**，选择铝、黄铜、钢、矿物 XRD 或 PET Raman 案例。

## 自有数据的操作

1. 选择力学、光谱或 XRD 任务，上传 CSV、TSV、TXT、DAT、XY、XYE 或 XLSX。
2. Excel 选择工作表和表头行。文本可自动识别，也可选数值 XY。更新预览，核对前 20 行、列类型和缺失率。
3. 从实际列名中选择横坐标和信号列，填写单位。
4. 力学填写弹性拟合区间和偏移应变；光谱、XRD 选择基线策略和峰突出度。
5. 点击 **检查方法条件**，处理缺少的信息或不适用的方法。通过后点击 **生成可编辑流程**。
6. 在画布中检查节点参数，点击运行。结果表、图片、HTML 报告和复现 ZIP 出现在会话附件中。

普通操作无需写 JSON，也无需配置模型。聊天仍可创建和修改流程；三类标准任务通过同一个协议编译器生成原生节点。已有批处理、分组、统计、其他材料节点继续保留。

## 三类任务

| 入口 | 必须确认 | 主要输出 | 专业解释范围 |
|---|---|---|---|
| 力学性能 | 工程应力/应变及单位、弹性拟合区间、偏移应变 | 弹性模量、偏移屈服、拟合诊断、应力—应变曲线 | 单次加载曲线；断裂需明确实验依据；不同选段可能产生不同模量 |
| 光谱特征 | 坐标定义、信号含义、基线、突出度 | 处理曲线、候选峰位置/宽度/面积和特征表 | 正峰提取；透射率谷需转换或采用相应方法，模式归属需参考证据 |
| XRD 表征 | 2θ、deg、强度单位、背景与突出度 | 候选衍射峰、结构化特征、图和报告 | 物相鉴定需参考谱；尺寸估计另需波长、展宽和模型条件 |

任务表单处理 20 MB 以内的一条曲线。重复坐标、循环加载和混合曲线需先分段或使用批处理节点。排序是显式选项，原始文件保持不变。9 个内置案例将各自必要的换算和筛选显示为节点。

## 方法知识

三个任务包各有 6 张方法卡和 12 项条件检查，共 18 张卡、36 项检查。每项包含观察值、预期条件、影响步骤和下一步建议。返回状态为可建流、需补信息或需调整方法；非阻断的注意事项仍显示在结果中。方法卡提供来源链接和版本。

方法检查验证声明参数与方法前提。它与运行成功、重复执行一致性分开记录；团队可在评测结果上追加独立材料专家判定。

## 中断后的继续与复现

工作流运行会将纯科学计算写入项目 `.checkpoints`。再次执行时重新读取输入，校验数据、参数、上游依赖、代码和环境指纹；匹配的计算直接复用。改参只影响对应计算及其依赖。导入、图表、文件导出和云端请求每次实际执行。失败或部分失败不会保存为成功检查点。

复现 ZIP 包含原始输入、实际运行的流程、建流时的方法检查、完整结果表、图表、报告、环境版本及文件哈希。解压后在安装了项目的环境中执行：

```sh
python -m materials_quality.agent.run_bundle ./解压目录
```

入口先核验哈希，再绑定本机输入路径，使用已安装的节点代码重跑。无需模型、个人 skill 或原电脑的绝对路径。新结果保存在包旁独立目录；原包不改写。

## 可重复的验收

在 `packages/materials-quality` 中运行：

```sh
python -m scripts.evaluate_material_instruments --output artifacts/material-instruments --repeats 3
python -m scripts.evaluate_agent_stability --output artifacts/agent-stability --repeats 3
python -m scripts.ui_material_task_acceptance
```

第一项编译 9 条原始仪器参考流程，冻结流程和哈希，在 3 个新 Python 进程中重跑，并做独立公式/寻峰定义对照。第二项检查已知解析答案的合成数据。第三项通过浏览器实际点击表单、画布运行和附件下载。

增加 `--live` 可测真实模型自动建流。模型配置通过 `STUDYUI_MODEL_BASE_URL`、`STUDYUI_MODEL`、`STUDYUI_MODEL_API_KEY` 环境变量提供。真实仪器 live 模式先按公开且固定的步骤准备测量表，再评估 Agent 建流；原始仪器转换能力在参考流程验收中单独计分。冻结后的冷启动重跑不接收模型凭据。

评测结果分别报告：建流完成比例、方法参数契约符合率、执行成功率、独立数值对照和跨进程重复性。专家判定是单独字段，未评分时明确留空。
