# 独立解析光谱与试验设计评测

适用版本：0.7.0。评测直接执行科学函数，真值来自独立生成参数或闭式统计公式。使用方法见[科研可靠性说明](research-reliability.md)，界面演示见[可靠性流程](../examples/reliability_flows/README.md)。

## 解析光谱：冻结任务、规则与分母

`materials_quality.evaluation.spectral` 默认生成 260 个任务，共 280 条曲线。开发集为 120 个任务，保留集为 140 个任务；20 个任务各含两条合法长表曲线。每个任务执行三种阈值策略和两种候选规则，共 1,560 次任务配置、1,680 条曲线配置记录。

开发集与保留集使用不同的宽度、幅度、噪声参数单元和不相交种子范围。开发宽度基值为 3/5 nm，保留宽度为 8/11 nm；保留集另有重叠肩峰与饱和机制。任务覆盖 730/790 nm 竞争峰、窗口外强峰、窗口边缘、非均匀坐标、噪声及纯噪声、线性背景、um 单位、非法单位、重复坐标和合法重复曲线编号。

生成器保存高斯中心、幅度、宽度及有限观测区间积分。匹配容差预先固定为 `max(1.25 nm, 2 × 最大采样间隔)`，峰采用一对一距离匹配。孤立、无噪声单峰可比较解析 FWHM；积分误差以可返回积分的曲线为条件。重叠和削顶后的成分中心不能直接充当可辨识局部峰真值，这些压力任务保留执行结果并明确标记候选真值不可评分。

候选评分以预定规则为真值，缺失和失败保留在分母；纯噪声任务以正确保留空候选为预期。错误候选、噪声误报、检出缺失和输入拒绝分别记录。零噪声参考无法估计 MAD 时，拒绝属于适当停止；报告同时保留其候选数值失败，避免通过删分母改善结果。

受控开发子集的验收在运行前固定：绝对阈值下，孤立峰、竞争峰、外部干扰、um 单位及非均匀坐标的指定样例须匹配全部真峰并正确选择候选。该检查验证可复算数值行为。保留任务的噪声性能按参数单元呈现，未设置统一的通过百分比，也未根据保留结果调整真值、阈值或容差。

### 已记录运行

`reliability-v2-independent-20261103-run2` 使用绝对突出度 0.15、物理间距 10 nm、参考噪声窗口 875–900 nm、噪声倍数 5。所有策略共同保留 295 条候选失败记录；240 条非法输入配置全部正确拒绝，另有 94 条原始输入合法但零噪声参考不可用的停止。主要候选结果如下，每格分母均为 110 条可评分曲线配置，含正例与纯噪声负例：

| 数据集 | 阈值策略 | 突出度最大候选正确数 | 最红端候选正确数 |
|---|---|---:|---:|
| 开发 | 旧版全谱相对阈值 | 90/110 | 80/110 |
| 开发 | 指定突出度阈值 | 105/110 | 101/110 |
| 开发 | 参考噪声窗口 | 64/110 | 60/110 |
| 保留 | 旧版全谱相对阈值 | 85/110 | 80/110 |
| 保留 | 指定突出度阈值 | 95/110 | 90/110 |
| 保留 | 参考噪声窗口 | 88/110 | 87/110 |

噪声、参考区间适用性和候选规则均影响结果。开发与保留参数区域不同，表中数值用于定位条件性失效；这些有限合成单元的混合准确率不代表真实仪器数据质量。

有限参数单元及共享任务上的多策略结果不构成 IID 总体抽样，光谱汇总明确不输出二项总体置信区间。位置 MAE、FWHM 和积分误差均附实际可用分母；逐案例记录与按参数单元分层结果可继续定位失败。

## 试验设计：独立随机模拟与统计公式

`materials_quality.evaluation.design` 默认运行 512 个独立模拟试验：每组独立单位数 4/8、技术重复数 1/3、总体差值 0/2、平衡/异方差，共 16 个预定单元，每单元 32 次试验。

每条技术测量为：`Y_gij = effect × I(g=A) + U_gi + ε_gij`。单位效应和技术噪声为独立正态抽样，同单位技术行共享单位效应。平衡情景的单位标准差为 (1,1)，技术噪声标准差为 (0.4,0.4)；异方差情景分别为 (1,2) 与 (0.7,0.3)。每次模拟使用独立 SeedSequence 子流，独立试验数按试验计数。

真实 `contrast_study` 接收技术行及正确单位编号。独立参照通过 Python 样本均值、样本方差、Welch–Satterthwaite 自由度及 Student t 分位数计算区间和 p 值，不调用生产聚合器或 t 检验函数。另一参照将技术行当作独立观测，量化忽略单位内相关的影响。聚合后组样本量、均值差、统计量、p 值和区间必须在预定绝对/相对容差 `1e-10` 内一致。

重点测试还比较配对 t 公式，并核查 n=1、n=2 的显式小样本政策。政策检查验证软件返回状态；统计覆盖与第一类错误由重复模拟估计。

### 已记录运行

`reliability-v2-design-20261103-run1` 完成 512 次独立试验，用时 11.54 秒；数值参照不一致 0 次，生产执行异常 0 次。下表完整列出零差值、三次技术重复的四个单元：

| 每组单位数 | 方差情景 | 单位聚合后第一类错误 | 逐行参照第一类错误 | 单位聚合后覆盖 | 逐行参照覆盖 |
|---:|---|---:|---:|---:|---:|
| 4 | 平衡 | 1/32 | 10/32 | 31/32 | 22/32 |
| 4 | 异方差 | 3/32 | 9/32 | 29/32 | 23/32 |
| 8 | 平衡 | 2/32 | 9/32 | 30/32 | 23/32 |
| 8 | 异方差 | 2/32 | 9/32 | 30/32 | 23/32 |

单次技术测量时，两种参照一致。总体差值为 2 的拒绝率记为指定差值下的功效。全部单元另报区间平均宽度及 Monte Carlo 标准误。

每单元 32 次的模拟精度有限。覆盖率与拒绝率提供实际分母、插件 Monte Carlo 标准误和 Wilson 95% 区间；这些不确定度适用于独立模拟试验的频率估计。单个实验的均值差区间与模拟频率区间分别记录。结果依赖所声明的正态设计和方差参数，未设统一覆盖率通过门槛；外部评审的 25%/1.7% 未作为实测事实使用。

## 重跑与证据

在组件包根目录及其已配置环境运行，输出目录必须尚不存在：

```powershell
python -m scripts.evaluate_reliability --output artifacts/analytic-001
python -m scripts.evaluate_reliability --split holdout --output artifacts/analytic-holdout-001
python -m scripts.evaluate_design --output artifacts/design-001
python -m scripts.evaluate_design --repetitions 64 --seed 20261103 --output artifacts/design-002
```

命令行的重复次数针对每个设计单元；64 次对应 1,024 个独立试验。扩大模拟次数用于提高精度，预定模型、评分与验收标准保持不变。

| 文件 | 光谱评测 | 设计评测 |
|---|---|---|
| 逐项 JSON/CSV | `per_case.json/csv` | `per_trial.json/csv` |
| 汇总 | `summary.json`，含分母、单元和失败任务 | `summary.json`，含频率、宽度、MCSE/Wilson |
| 运行清单 | `manifest.json`，含真值、种子、配置、源文件哈希、Git/环境 | 同名，含模型、独立 RNG 策略及参照公式 |
| 完整性 | `artifact_hashes.json` | `artifact_hashes.json` |

上述历史运行位于仓库根目录的 `artifacts/reliability-v2-independent-20261103-run2/` 与 `artifacts/reliability-v2-design-20261103-run1/`。示例重跑命令写入组件包内 `artifacts/`；两处均为忽略的生成记录，源代码与评测定义随仓库管理。每次结果以自身清单中的源码哈希、提交、依赖、配置和种子解释；历史记录不替代最终提交验收。

当前记录覆盖合成数值与设计模拟。最终安装、原生表单、保存重开、全量回归和 CI 证据需在对应固定提交的验收记录中核对。自主修订策略和真实论文数据逐峰验证尚无评测结果。
