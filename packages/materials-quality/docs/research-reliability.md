# 科研分析的候选、试验单位与数据契约

适用版本：0.7.0。使用入口为“科研技能·任务规划”和“科研技能·分析执行”，普通操作通过下拉框、数值框和确认框完成。示例见[可靠性流程](../examples/reliability_flows/README.md)，评测方法与实测记录见[独立评测](evaluation-reliability.md)。

## 光谱候选及规则

`window_candidate_nm` 是显式窗口内选出的光谱候选位置，单位固定为 nm。`lambda10_nm` 保留为数值相同的兼容别名；已有 `lambda10_*` 参数和结果字段继续可用。候选的物理模式归属需要实验条件与独立证据支持。

| 界面选择 | API 值 | 选择行为 |
|---|---|---|
| 突出度最大候选 | `highest_prominence` | 窗口内突出度最大者；并列时选波长较大者 |
| 最红端候选 | `redmost` | 窗口内波长最大者；突出度用于并列排序 |

原生表单使用 `selection_rule`；底层 `analyze_spectra` 使用 `lambda10_selection`。峰位为检测到的采样点位置。730 nm 强峰与 790 nm 较弱峰同时通过检测时，两种规则分别选出 730 nm 和 790 nm。

每条曲线输出 `selection_rule`、`candidate_count`、`ambiguous` 和 `detection_status`。状态包括 `candidate`、`ambiguous_candidate`、`missing_candidate`；两种规则均保留多候选歧义。逐曲线表保留失败和缺失，峰特征表保留所有检测峰。

## 阈值、噪声与坐标

| 界面选择 | `prominence_mode` | 配置与解释 |
|---|---|---|
| 旧版全谱相对阈值 | `legacy_relative` | 阈值为处理后全谱极差的 5%；窗口外强峰会改变阈值 |
| 指定突出度阈值 | `absolute` | 填写正的 `prominence`，单位为基线校正、平滑后信号的强度单位 |
| 参考噪声窗口 | `noise_reference` | 确认背景区间，使用 `noise_multiplier × 1.4826022185 × MAD` |

指定阈值与噪声阈值在归一化前应用。只含 `prominence` 的旧 API 配置按绝对阈值处理；同时声明冲突来源会报错。

候选窗口上下限统一填写 nm。噪声窗口和物理峰间距使用输入横坐标单位：输入为 um 时，0.01 表示 10 nm。“参考噪声窗口”还需勾选 `noise_confirmed` 对应的“确认下方区间适合估计背景噪声”，区间内至少有 5 个测量点，且 MAD 必须为正。漂移、参考区间污染和相关噪声会影响估计；倍数阈值本身没有校准误报概率。

启用“指定物理峰间距”后，`peak_distance_x` 按实际坐标限制峰间隔，适用于非均匀采样；算法按峰高从大到小抑制过近峰，峰高相同时优先较小坐标。旧 `peak_distance` 仍以采样点计，两项同时配置时均生效。非均匀网格直接保留原坐标，Savitzky–Golay 平滑仍要求等间隔采样。

## 独立单位与条件均值

规划节点提供三种“统计单位与比较方式”：

| 界面选择 | API `unit_mode` | 汇总和推断 |
|---|---|---|
| 仅描述曲线（未声明独立单位） | `descriptive` | 保留曲线描述和检出分母 |
| 每条曲线是独立单位 | `curve` | 以曲线为独立单位，需确认实验依据 |
| 按样品汇总后比较 | `sample` | 选择独立单位列，将同单位的技术曲线候选取均值后比较 |

后两种方式需勾选 `unit_confirmed` 对应的“确认所选单位在组间独立，技术重复按单位汇总”。一条曲线只能映射到一个单位，独立设计的同一单位不能跨组。配对数据使用“组间研究”任务并声明 `paired`。

分组表分别报告总曲线数、可分析曲线数、检出数、歧义数、失败数和跳过数。检出比例的分母为可分析曲线数。候选均值以检出候选为条件；缺失候选保持缺失，独立单位比较另列全部声明单位数及有候选的单位数。增加技术曲线改善单位内描述，独立样本量仍按实际试验单位计数。

## 小样本、差值区间与光谱置信带

默认 `small_sample_policy="descriptive"`：任一组少于 3 个独立单位时仅输出描述，p 值和差值区间保持缺失，`ci_status="not_estimated_small_n_policy"`。每组达到 3 个单位后，仍需检查独立性、分布、退化和设计适用性。

高级设置“显式模型推断（需检查假设）”对应 `model_based`。每组 n=2 时，可在明确模型假设下输出 Welch 或配对 t 推断，并标记 `estimated_small_n_model_assumptions`。n=1 仍保留描述；零方差等退化情况明确记录不可估计原因。

组间研究先按“变量 × 组别 × 独立单位”平均技术重复，再比较单位均值。参数策略输出 `mean_difference`（A−B）、`mean_difference_ci_low/high`、`ci_method`、`ci_status` 和置信水平。独立设计使用 Welch 区间，配对设计使用配对差值的 t 区间。Holm/FDR 校正适用于所声明比较族的 p 值；这里的差值区间为单个比较区间，未作同时区间校正。秩检验路径保留其统计结果，均值差区间标记为未估计。

`iqr` 和 `sd` 展示逐波长分布；`ci95` 展示均值逐点 t 区间。`ci95` 要求已确认独立单位：先在单位内求完整均值曲线，再以单位曲线估计组均值区间。默认每组至少 3 个单位，`model_based` 时至少 2 个。测量网格不一致时停止生成置信带，保留数值结果与原因；网格对齐需显式完成。逐点区间覆盖的解释针对单个波长。

经验 Bootstrap 需单独声明独立性，并记录样本数和退化状态；默认 n<3 或重采样退化时保留原因、停止输出区间。参数敏感性、统计区间与仪器校准误差分别解释。

## 表格契约与计划一致性

`studyui-table-contract/1` 记录粒度、角色列、单位来源、试验设计、聚合与派生历史，并生成规范化 `contract_sha256`。数值表指纹保留原版本；语义哈希独立绑定到计划。

| 粒度 | 每行的含义 | 典型用途 |
|---|---|---|
| `point` | 曲线上的一个坐标点 | 原始及处理后光谱、力学曲线 |
| `measurement` | 一个标量测量或技术重复 | 组间研究输入长表 |
| `peak` / `curve` | 一个峰 / 一条曲线的汇总 | 峰特征、窗口候选 |
| `sample` / `experimental_unit` | 样品或单位层汇总 | 力学指标、单位均值 |
| `group_summary` | 分组统计或比较结果 | 描述和推断汇总 |

`measurement` 长表允许同一单位的不同技术重复。`point` 的逐坐标值需要先提取合适的标量特征，再进入组间研究。`sample_id` 与 `experimental_unit` 表达同一实体时可以同列；已确认曲线独立时，曲线编号也可承担单位角色。正常长表中的重复曲线编号合法，曲线内重复横坐标另行校验。

规划记录输入身份及有效分析契约，执行前重新校验。数值、单位、角色、粒度或设计变更后，重新运行规划节点；旧的无契约计划也需重新生成。模型建议通过参数白名单与确认检查，科学声明由已确认的输入产生。

结果表在 `DataFrame.attrs`、结构化信封和批次传输中携带契约；报告记录各输出的真实粒度和契约。CSV 数值文件配合 `report.json` 中的表格元数据保存完整解释。已登记的筛选、重命名和聚合等操作更新契约；未知转换清除原有语义声明并附原因，冲突需复核。

## 运行记录与适用范围

每次执行创建独立目录，报告包含方法、参数、状态、输入/契约身份和文件哈希。复核以具体提交、环境、命令与输出目录为单位；最终 UI 保存重开、安装发现、全量测试与 CI 结果另以验收记录为准。

当前交付包含数值补强、语义契约、表单和独立合成评测。自主修订闭环及真实论文数据的逐峰验证尚未实现；真实数据需补充来源、仪器条件和独立标注。
