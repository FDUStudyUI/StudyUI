# StudyUI Demo 视频说明与录制脚本

状态：录制准备稿。视频文件、实际时长与实际时间轴待录制后填写。建议总长约 4 分钟；3–5 分钟为团队安排建议。

## 录制前准备

按[评委运行说明](05_代码运行说明.md)启动界面，使用[三个合成数据流程](../packages/materials-quality/examples/skill_flows/README.md)。三个 Skill 已完成本地真实界面与报告图像检查；录制前确认运行的是最终提交版本。保留浏览器、终端和报告输出，关闭无关页面及密钥显示。

三个示例均为“数据源 → 科研技能·任务规划 → 科研技能·分析执行”。同一数据源同时连接规划器和执行器，规划器另向执行器提供计划。默认关闭模型建议，基础演示无需云模型。

## 录制检查

1. 画面中显示真实点击、等待和结果；可以剪去安装与长等待，剪辑处保持操作含义连续。
2. 数值、单位、样本量与当前输出核对一致；若结果不符，先查原因并更新脚本。
3. 候选窗口修改后先重跑规划器；恢复原参数后也按相同步骤刷新计划。
4. 打开的是本次运行生成的 HTML，检查图像正常显示。服务器上的路径需通过对应运行机器访问。
5. 使用合成数据标记，避免展示私人路径、账号、密钥或真实未授权实验数据。
6. 录制完成后填写实际时间轴并完整回放 MP4，检查文字可读、声音清楚和文件可播放。
