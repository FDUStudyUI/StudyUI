# StudyUI 评委运行说明

组件包：`langflow-materials-quality 0.6.0`。提交 commit、最终验证日期和环境由团队在正式提交前填写。

## 运行条件

- 安装 Python 3.10；提供 Windows 与 macOS/Linux 启动脚本，界面目标为 Langflow 1.13.0。当前本地验收环境为 Windows，其他平台需按本说明复跑。
- 首次安装需要网络以获取依赖。基础示例无需云模型账号、API 密钥或 Intel 专用加速设备。
- 启动器使用项目根目录独立的 `.demo-venv`，默认监听 `127.0.0.1:7880`。请在运行机器的浏览器访问。

以下命令均在包含 `start_demo.bat` / `start_demo.sh` 的项目根目录执行。

## 首次安装与启动

Windows PowerShell：

```powershell
.\start_demo.bat --setup
```

macOS/Linux：

```bash
bash ./start_demo.sh --setup
```

安装完成并启动后，打开 [StudyUI 演示界面](http://127.0.0.1:7880)。首次安装耗时取决于网络和机器，终端会输出进度。双击 Windows 启动器或无参数执行脚本，也会默认进行 `--setup`。运行过程中保留终端，结束后用 `Ctrl+C` 停止服务。

环境已准备好时，再次启动：

```powershell
.\start_demo.bat --port 7880
```

macOS/Linux 对应为 `bash ./start_demo.sh --port 7880`。

只读检查依赖与运行条件：

```powershell
.\start_demo.bat --check
```

macOS/Linux 对应为 `bash ./start_demo.sh --check`。检查不会安装依赖或启动服务；缺少环境时按提示运行 `--setup`。

## 运行三个示例

启动器会尝试预载演示流程。若终端提示预载失败，请在首页使用导入功能，选择以下 JSON；终端也会打印导入路径。数据已嵌入流程，无需准备实验数据。

| 场景 | 导入文件 | 检查结果 |
|---|---|---|
| 光谱 | [spectra.json](../packages/materials-quality/examples/skill_flows/spectra.json) | 8 条曲线、16 行峰特征；A/B 各 4 条窗口候选，均值 715/755 nm |
| 力学 | [mechanics.json](../packages/materials-quality/examples/skill_flows/mechanics.json) | 20 个样品完成；首份模量 200000 MPa、偏移强度约 202.01005 MPa |
| 组间研究 | [contrast.json](../packages/materials-quality/examples/skill_flows/contrast.json) | 24 行技术测量聚合成 8 个试验单位，两组各 n=4 |

操作顺序：

1. 打开流程，查看左侧合成数据源、中间“科研技能·任务规划”、右侧“科研技能·分析执行”。
2. 打开规划节点，检查任务、列映射、单位与区间；示例已给定合成数据适用条件。运行规划节点，查看“步骤与待补事项”。
3. 计划就绪后运行执行节点。查看“逐样品/试验单位结果”“结构化特征/两两比较”“分组描述统计”和“结果摘要”。
4. 在“图件与导出文件”查看本次运行的实际路径，打开 `report.html`，核对图、表、方法和追溯。

修改参数后，先重新运行规划器，再运行执行器。以光谱窗口下限 650→720 nm 为例，新预期为 A 组 2 条有效候选、均值 725 nm；B 组 4 条、均值 755 nm。改回 650 后重新规划并执行即可恢复。

## 输出与使用范围

每次执行生成独立结果目录，包含结果 CSV、图件、自包含 HTML、JSON 记录及 `manifest.json` 文件清单。实际文件名与路径以“图件与导出文件”为准；文件位于部署电脑或服务器。SHA-256 是完整性指纹。

三个示例全部为合成数据。光谱窗口、力学单位及弹性区间、统计试验单位与设计需要按实际研究确认。异常值标记、候选峰和追溯校验各有明确含义，不能直接作为实验真实性或材料合格的判定。

## 可选命令行复跑

网页演示为推荐入口。需要命令行时，使用 `.demo-venv` 中的 Python；以下为 Windows 示例：

```powershell
cd packages/materials-quality
..\..\.demo-venv\Scripts\python.exe -m materials_quality.skills list
..\..\.demo-venv\Scripts\python.exe -m materials_quality.skills run examples/skill_flows/spectra.csv --task spectra --x-unit nm --y-unit counts --peak-window 650 850 --baseline constant --baseline-value 2 --data-kind synthetic --output artifacts/evaluator-spectra
```

macOS/Linux 对应 Python 路径为 `../../.demo-venv/bin/python`。参数通过普通命令行选项填写，无需编写 JSON。[科研技能指南](../packages/materials-quality/docs/research-skills.md)提供力学、统计与字段映射用法。

## 常见情况

| 情况 | 处理 |
|---|---|
| 找不到 Python 或版本不符 | 安装 Python 3.10 后重新运行；保留终端错误以核对实际解释器 |
| 首次安装失败 | 查看终端网络或依赖错误，修复后重跑 `--setup`，再用 `--check` 检查 |
| 7880 端口已占用 | 使用 `--port 7886` 等空闲端口启动，并打开对应地址；已有服务不会被接管 |
| 浏览器没有三个演示 | 按上表手动导入 JSON，确认启动的是本项目提供的环境 |
| 提示科学条件待补 | 在规划节点补齐单位、窗口/弹性区间、试验设计，再运行规划与执行 |
| 报告路径打不开 | 在部署机器访问实际输出路径；远程部署需获取服务器生成文件 |
| 修改后结果未刷新 | 先重跑规划节点，确认新计划，再执行；检查是否误开另一个服务实例 |

## 模型与数据

基础示例默认不调用模型。主动启用模型建议时，需配置兼容 chat-completions 服务；程序发送任务描述、列结构、行数、缺失计数等信息，不自动发送原始行。描述中写入的内容会随请求发送。数据计算发生在 Langflow 部署位置，远程模型或其他网络节点的访问范围由实际配置决定。
