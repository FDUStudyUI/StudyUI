## 推荐评审入口

主赛道选择“智慧学习与科研助手”。从“任务规划 → 科学条件确认 → 受控执行 → 图表与追溯”展示完整任务，建议先演示光谱，再展示力学和组间研究。主线采用三个内置 Skill 与合成数据，基础运行无需云模型或 API 密钥。

组件包交付目标为 `0.6.0`，含 62 个原生节点及三个内置 SKILL.md。当前科研技能三个任务的本地真实界面与报告图像检查已通过，见[科研技能验收](../packages/materials-quality/docs/research-skills-acceptance.md)；启动器最终验收、远程 CI 和最终提交 commit 另行核对。[参赛对齐与证据清单](../packages/materials-quality/docs/contest-readiness.md)记录外部建议的采纳依据、已知事实及待核验事项。
